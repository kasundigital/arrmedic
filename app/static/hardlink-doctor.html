HARDLINK HEALTH

Filesystem compatibility

Hardlinks only work when downloads and media are on the same filesystem. ArrMedic compares visible filesystem device IDs and explains the result.

SIMPLE EXPLANATION

What should I do?

For Docker media stacks, a common layout is one shared host mount such as /data, then use /data/downloads and /data/media inside Radarr/Sonarr. If the folders are on different filesystem devices, hardlinks cannot work and imports may copy files instead.

Recommended patternHost: /data Radarr/Sonarr: /data Downloads: /data/downloads Media: /data/media
